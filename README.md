## 👨‍💻 Sobre o projeto

Este repositório contém meu **portfólio pessoal**, desenvolvido para apresentar minha trajetória como estudante de Desenvolvimento de Sistemas, meus conhecimentos, projetos e experiências na área de tecnologia.

O objetivo é reunir meus principais trabalhos em um único lugar, permitindo que outras pessoas conheçam meu processo de aprendizado e evolução como desenvolvedor.

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Recrocs/portfolio.git
```

2. Entre na pasta:

```bash
cd portfolio
```

3. Abra o arquivo:

```text
index.html
```

Também é possível utilizar uma extensão como **Live Server** no VS Code para executar o projeto localmente.
